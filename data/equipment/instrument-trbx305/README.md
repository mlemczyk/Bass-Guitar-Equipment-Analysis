# Yamaha TRBX305 (instrument)

5-string bass, 34" scale, standard tuning B0-E1-A1-D2-G2, D'Addario steel
roundwounds (.135 low B), stock Yamaha M3 dual-coil pickups, EMG BQC
preamp (`../emg-bqc/`). Full description in `rig.md`.

**Findings: [`findings.md`](findings.md)**: string decay, where the top end
goes, pluck tool and position, pickup pan.

## Files

- `measurements/string_decay.json`: 3,313 per-partial decay fits (take,
  string, fret, harmonic, frequency, dB/s, fit quality). Schema:
  `rig-equipment/partial-decay@1`, columns documented in the file.

The played takes behind these (R-series) are performances, not test
signals. The pluck-block and scale takes (R25–R27, R33–R36) are exercises,
but they are not published either, to keep the rule simple: no played audio.
