# Stimuli

The probes every capture in this dataset was made with: 44.1kHz, 24-bit mono.
`generate.py` rebuilds them from `rig_dsp/stimuli.py` and compares; all nine
generated files match the committed ones to within 1 LSB of 24-bit (checked
2026-10-21).

| file | what | used for |
|---|---|---|
| `ess_ladder.wav` | 8s exponential sweep 15Hz–20kHz at −60/−50/−40/−30/−20dBFS, 1.5s gaps, 1s lead | **standard** frequency response + linearity + harmonics |
| `ess.wav` | one 20s sweep, −12dBFS peak | early single-level captures (superseded) |
| `ess_inverse.wav` | matched inverse filter for `ess.wav` | deconvolution; never played |
| `levels.wav` | eight 1.5s steps of 110Hz, −52 to −15dBFS, 0.5s gaps | static nonlinearity: harmonics against level |
| `pink.wav` | 20s pink noise, seed 20260913 | graphic-EQ band curves (early) |
| `silence.wav` | 10s digital silence | noise floor |
| `twotone.wav` | 437/1249/3527Hz held at −38dBFS while 80Hz steps −55 to −15 | multiband vs broadband compression |
| `bursts.wav` | 110Hz alternating −14/−44dBFS (1.5s/3.5s) ×5 | attack and release times |
| `plucks.wav` | synthetic 55Hz plucks vs per-harmonic RMS-matched steady tones | program dependence |
| `emg_sweep.wav` | sweep for magnetic injection into the pickups | EMG preamp; not generated by `generate.py` |

At re-amp time each file is rescaled to a send peak level
(`send_peak_dbfs` in the measurement files), keeping its internal level
structure.
